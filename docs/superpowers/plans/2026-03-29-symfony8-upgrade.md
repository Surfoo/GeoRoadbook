# Symfony 8 + PHP 8.4 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade GeoRoadbook from Symfony 7.1 / PHP 8.3 to Symfony 8.0 / PHP 8.4 without changing any product behavior.

**Architecture:** Pure dependency and compatibility upgrade — no feature changes. Three layers of work: (1) fix two PHP source incompatibilities, (2) update `composer.json` version constraints and remove dropped packages, (3) run composer update and refresh Symfony recipes.

**Tech Stack:** PHP 8.4, Symfony 8.0, Composer 2, Symfony Flex recipes

---

## Current state summary

- Symfony **7.1.0** installed, PHP **8.5.4** running locally
- `composer.json` targets `^7.0` for all Symfony packages and `"php": ">=8.3"`
- Two source-code issues that will break under Symfony 8:
  - `src/Controller/OAuthController.php` imports `Routing\Annotation\Route` (compatibility shim removed in Symfony 8; must use `Routing\Attribute\Route`)
  - `src/Security/GeocachingAuthenticator.php` has an implicit nullable parameter (`AuthenticationException $authException = null`) — deprecated in PHP 8.4, broken in PHP 9
- `symfony/proxy-manager-bridge` is pinned to `^6.4` in `composer.json` but the package was abandoned after 6.4 and does not exist in Symfony 7/8 — must be removed
- `composer/package-versions-deprecated` is no longer needed with Composer 2 — remove it

## Task 1: Fix `Annotation\Route` → `Attribute\Route`

**Files:**
- Modify: `src/Controller/OAuthController.php:9`

The `Symfony\Component\Routing\Annotation\Route` compatibility shim (which just class-aliases to `Attribute\Route`) is removed in Symfony 8. Use the real class.

- [ ] **Step 1: Edit the use statement**

In `src/Controller/OAuthController.php`, change line 9:

```php
// Before
use Symfony\Component\Routing\Annotation\Route;

// After
use Symfony\Component\Routing\Attribute\Route;
```

- [ ] **Step 2: Verify the file looks correct**


- [ ] **Step 3: Commit**

```bash
git add src/Controller/OAuthController.php
git commit -m "fix: use Routing\\Attribute\\Route (Annotation alias removed in Symfony 8)"
```

## Task 2: Fix implicit nullable type in `GeocachingAuthenticator`

**Files:**
- Modify: `src/Security/GeocachingAuthenticator.php:83`

PHP 8.4 deprecates implicit nullable parameters (`Type $param = null` without the `?`). Fix before upgrading so the change is isolated.

- [ ] **Step 1: Edit the method signature**

In `src/Security/GeocachingAuthenticator.php`, change line 83:

```php
// Before
public function start(Request $request, AuthenticationException $authException = null): Response

// After
public function start(Request $request, ?AuthenticationException $authException = null): Response
```

- [ ] **Step 2: Verify**

```bash

```
Expected:
```
    public function start(Request $request, ?AuthenticationException $authException = null): Response
```

- [ ] **Step 3: Commit**

```bash
git add src/Security/GeocachingAuthenticator.php
git commit -m "fix: explicit nullable type for AuthenticationException (PHP 8.4 deprecation)"
```

## Task 6: Update Symfony recipes

**Context:** `composer recipes:update` updates config files managed by Symfony Flex recipes (e.g., `config/packages/framework.yaml`, `bin/console`, `public/index.php`). It will prompt for each changed recipe — accept all unless there is a conflict with project-specific config.

- [ ] **Step 1: Run recipes update**

```bash
composer recipes:update
```

For each recipe, Flex will show a diff and ask whether to apply. Accept all. If a recipe touches a file you've customized (like `config/packages/security.yaml`), review the diff carefully — the command may create `.orig` backup files.

- [ ] **Step 2: Review any conflicts**

```bash
git diff config/
```

Check that:
- `config/packages/framework.yaml` — any new keys added by Symfony 8 are acceptable defaults
- `config/packages/security.yaml` — your custom firewall/authenticator config is intact
- `config/packages/monolog.yaml` — logging channels preserved

- [ ] **Step 3: Commit recipe updates**

```bash
git add config/ bin/ public/index.php symfony.lock
git commit -m "chore: update Symfony recipes for 8.0"
```
