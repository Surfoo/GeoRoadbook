FAQ
My language isn't in the list, how to get it?
You can translate this file and make a pull request on GitHub or send it by email. I'll add it quickly then.
Why does my roadbook no longer exist?
All roadbooks are kept 1 month after the last modification date. You can know the date with a hover on the "Save" button, and if you save it, it'll be kept again.
Is my roadbook public and published on internet?
No, your roadbook is absolutely private and it doesn't appear on search engines. Only you know the link, and you should keep it private if you prepare an event.
Your roadbook can't be found with tests on the URL, the identifiers are random.
Why doesn't my GPX file work?
Only GPX files with the version 1.0.1 are managed, if you don't know the version, check your preferences.
GPX with tracks are not supported. If your file still doesn't work, it may be corrupted.
Why can't I see spoilers in the roadbook?
Unfortunately, the links to spoilers aren't included in the GPX file, maybe one day Groundspeak will fix this, who knows?
If you want spoilers in the roadbook, you should insert them manually with the image button or use my web app Spoilers4gpx.
Why is pagination missing in the table of contents?
The rendering engine doesn't implement this feature yet. You should add the pagination manually after a first PDF export.
You can also use the Print Preview in your browser with the roadbook in HTML view.
Why does my roadbook look good in the editor and not in the PDF?
The PDF rendering is great but some HTML/CSS features aren't implemented yet.
I have a problem with GeoRoadbook, what can I do?
If you find bugs, please open an issue on GitHub, or contact me.
